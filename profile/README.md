# OWEmb Technologies

*Engineering Practice*

OWEmb Technologies is an engineering practice founded by Christian OWONO PETHER.

We engineer technology platforms that stand the test of time.

Our mission is to help organizations architect, build and industrialize embedded, connected and cloud-enabled systems that are reliable, secure and maintainable by design.

This organization hosts the engineering work of OWEmb Technologies, including reusable libraries, reference architectures, embedded platforms, tooling and open-source initiatives developed to support production-grade systems.

## Focus Areas

* Platform Architecture
* Embedded Systems & Embedded Linux
* RTOS & Edge Computing
* IoT & Connected Platforms
* Cloud & Backend Engineering
* DevSecOps & CI/CD
* Open Source Engineering

## Engineering Principles

* Architecture before implementation
* Design for longevity
* Security by design
* Simplicity over complexity
* Automation wherever possible
* Build to last
